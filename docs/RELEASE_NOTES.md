# 1.1.0-alpha.3

- 修复 GUI 缩放触发的重复画面缓冲重建：在 D3D12 上，实际像素尺寸未改变时复用现有主缓冲，保留原有深度测试和 framebuffer 绑定状态。
- 实际窗口像素尺寸变化或缓冲尚未创建时仍使用原来的重建流程；DX12 禁用时不修改此行为。
- 增加连续 12 次 GUI 缩放、主颜色纹理复用、界面尺寸有效性和进入世界/保存退出检查。

修复前，连续缩放测试在保存完成后的退出阶段出现 Windows 原生堆损坏 `0xC0000374`。修复后的 Java 25 / Loader 0.19.3 / LWJGL 3.3.1 检查完成了 12 次缩放、世界渲染、截图和保存退出，画面截图不是黑屏。Java 17 在窗口销毁时仍有 Mesa 原生崩溃，因此不作为该修复的稳定性证据。这是本地复现路径的修复，尚不保证所有窗口/全屏切换和长期运行稳定。

# 1.1.0-alpha.2

实验版：Minecraft 1.19.2 / Fabric / Windows x64。

- 增加 Sodium 0.4.4 的 D3D12 绘制兼容路径，自动将批量索引绘制拆分，规避 Iris 光影测试中的 Java 堆外内存持续增长。
- 保留每次绘制的索引偏移与基础顶点，不复制缓冲、不改变缓冲位置；禁用 DX12 时沿用原绘制调用。
- 增加 Iris 实际启用、失败回退、光影关闭/开启/重载和保存退出检查；隔离测试脚本记录内存并在超限时停止测试。
- 游戏测试使用 Java 17；无需用户添加启动参数。Iris、Sodium 和光影包仍需单独安装。

实测记录和安装组合见 [Iris 光影](SHADERS.md)。这是驱动调用路径的规避修复，不代表 Mesa 上游问题已解决。仍未验证长期运行、其他显卡或全部光影选项，不能保证零崩溃或性能提升。

# 1.1.0-alpha.1

实验版：Minecraft 1.19.2 / Fabric / Windows x64。

- 默认通过内置 Mesa 26.2.4 D3D12 执行 GPU 绘制和呈现，无需参数或独立 DLL。
- 驱动自动释放与校验，F3 只有在核验实际 D3D12 设备后才显示启用。
- 移出旧 JNI / C++ 原型，使用正式包名，固定 Loom 版本。
- 提供中英文说明、实机截图、路线图、贡献指南和 CI 构建。

升级时只保留一个 dx12mod JAR，选择普通 JAR 而非源码包。

Intel UHD 的网格、贴图、深度、透明混合、帧缓冲和呈现检查通过；世界与保存验证记录见 README。其他显卡、Java 25 / Loader 0.19.3 游戏组合、渲染模组及长期运行尚未验证，没有性能提升或零崩溃保证。

游戏仍使用 OpenGL API，由 Mesa 转为 D3D12。第三方来源与许可证随 JAR 提供。
