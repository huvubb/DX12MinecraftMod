# 日志与稳定性

确认 F3 显示实际 `D3D12 (显卡名称)`，或日志包含 `[DX12] ACTIVE`。世界成功显示与正常保存不能证明长期稳定或所有模组兼容。

## Sampler2 警告

`rendertype_entity_translucent_emissive could not find sampler named Sampler2` 是 Mojang 记录的原版问题 [MC-249414](https://bugs.mojang.com/browse/MC/issues/MC-249414)，报告覆盖 1.19.2。含义是着色器声明的纹理采样器没有在编译后程序中找到，单独这条日志不能证明 DX12 故障。若发光或透明材质实际异常，仍需提供复现。

## 未知实体乘客

`Received passengers for unknown entity` 表示客户端收到乘坐关系更新时，找不到对应的载具实体，无法应用该次关系更新。实体出现/移除的同步时序可能参与触发，但本次日志没有实体 ID，无法确定具体对象或原因。

此前世界检查出现一次，之后正常运行并保存。若持续出现或伴随船、矿车、骑乘异常，应调查实体同步；目前没有证据将它归因于 DX12。

## 其他已见情况

### GUI 缩放后退出或崩溃

alpha.2 的连续 GUI 缩放检查曾在保存完成后的退出阶段触发原生堆损坏 `0xC0000374`。alpha.3 避免在实际像素尺寸相同时反复销毁/重建主画面缓冲，并保持原版绘制目标状态；GUI 缩放和界面布局仍正常更新。复现记录：12 次 0/1/2/3 缩放循环、颜色纹理保持不变、世界渲染截图不是黑屏、保存退出。

用户最初提供的实例日志记录退出码 0、没有新崩溃报告，因此不能将每一次窗口消失都直接认定为该原生错误。若升级后仍退出，应提供本次最新日志、启动器退出码或 Windows 应用错误事件。

Iris + Sodium 0.4.4 在旧版后端上触发过 Java 堆外内存持续增长：游戏进程提交量约 32GB，随后 `GL_OUT_OF_MEMORY` 和 Mesa DLL 内访问异常。Java 堆并未耗尽，因此降低 `-Xmx` 不能解决。alpha.2 在核验 D3D12 后，将 Sodium 的批量索引绘制拆为逐次绘制；日志应包含 `Sodium draws submitted individually`。该规避仅覆盖已测试的版本与设备，详见 [光影检查](SHADERS.md)。

- `Unsupported JNI version detected` 来自 LWJGL，提示运行时兼容风险；一次成功运行不足以证明无害。
- 开发账号的密钥 / Realms 认证失败应与渲染错误分开检查。
- 此前资源下载失败并跳过下载，产生缺失音效警告，因此没有验证音效完整性。正常检查应完成资源下载。

若另一模组提前加载系统 OpenGL 驱动，在仅安装本模组的实例中复现。校验、解压失败需检查资源完整性、权限或文件占用，不要把 DLL 放进系统目录。

可临时使用 `-Ddx12.disable=true` 排查。反馈提供复现步骤、环境和脱敏日志；JVM 崩溃时附相关 `hs_err_pid*.log` 调用栈。
